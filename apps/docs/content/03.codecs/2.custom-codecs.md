## defineCodec

`defineCodec` turns a URL format into a codec factory. The factory takes the same options as the built-in ones, so your codec gets `default`, `validate`, `historyMode`, and `omitDefault` for free:

```ts twoslash
import { defineCodec, useQueryState } from '@chronicstone/vue-route-query'
// ---cut---
const rangeCodec = defineCodec<[number, number]>({
  parse(raw) {
    const [min, max] = raw.split('..').map(Number)
    return min !== undefined && max !== undefined && Number.isFinite(min) && Number.isFinite(max)
      ? { ok: true, value: [min, max] }
      : { ok: false, issue: { reason: 'format', message: 'expected min..max' } }
  },
  serialize: ([min, max]) => `${min}..${max}`,
})

const price = useQueryState(
  'price',
  rangeCodec({ default: [0, 500], validate: ([min, max]) => min <= max }),
)
// ?price=10..200
price.value
//    ^?
```

- **`parse(raw)`** gets the raw string, already URL-decoded. Return `{ ok: true, value }`, or `{ ok: false, issue }` to reject it. The issue's message shows up in [`issues`](/guide/validation#see-what-a-link-got-wrong).
- **`serialize(value)`** returns the string to write, or `null` to remove the key.
- A `parse` or `validate` that throws is caught and treated as a rejection.

Keep the two symmetric: `parse(serialize(value))` should give back an equal value. That is what makes a shared link restore the same screen.

## Objects backed by a schema

`schemaCodec` stores a whole object as JSON in one key, and checks it with any [Standard Schema](https://standardschema.dev){target="_blank"} library: Zod, Valibot, or ArkType. The schema is both the type and the rule.

```ts twoslash
import { schemaCodec, useQueryState } from '@chronicstone/vue-route-query'
import { z } from 'zod'
// ---cut---
const sort = useQueryState(
  'sort',
  schemaCodec(z.object({ key: z.string(), direction: z.enum(['asc', 'desc']) }), {
    default: { key: 'createdAt', direction: 'desc' },
  }),
)
// ?sort={"key":"name","direction":"asc"}

sort.value.direction
//         ^?
```

- The package has no runtime dependency on any validation library. It calls the schema through the Standard Schema interface.
- Schemas must be synchronous, because reading a ref is synchronous. An async schema is rejected with a clear issue.
- JSON keeps nested state in one key, at the cost of a less readable URL. For flat filters, prefer one key per field with [`useQueryStates`](/guide/grouped-values).
